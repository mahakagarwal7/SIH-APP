## Behavior and scope

On the connected Android phone, one previously submitted outbox receipt had a
future work date. Applying the newer date-entry rule while loading that receipt
threw an exception for the entire outbox: My reports disappeared, voice review
stayed at preparation, and unrelated uploads could not proceed. Historical
receipts now load without reapplying new-entry limits; new confirmations still
reject future dates. Available reports remain visible if another local store
cannot be read, and failed voice preparation exposes its reason and retry.

This single follow-up to PR #38 also restores Home/My work/hierarchy link-card
styling, keeps manager claim details inside the four-tab navigation, explains
disabled review actions, refreshes related views after decisions, makes the
149-activity confirmation selector searchable, and reduces header/capture
spacing. Missing accepted progress remains unknown instead of becoming zero.
Report cards identify remote reports by project and current wording. Account
shows the app version, Android build and CI source commit. New copy is localized
in Hindi as well as English.

## Manual device checks

1. Install the new APK as an update, without clearing app data. Open Account and
   compare Source with the build manifest; an old APK cannot gain changes merely
   because a PR merged.
2. Open My reports with existing drafts/receipts. Reports should remain visible.
   Record voice, select today, submit, and watch upload, transcription and
   submission as distinct states. Check the same receipt in the web app.
3. Save a clearly marked test report offline, restart, reconnect, check its
   wording/date and send. Repeated sync must not create another capture/report.
4. Open Home, My work, project schedule, hierarchy, manager Overview/Review and
   a claim detail. Check readable cards, unknown-progress labels, exactly four
   manager tabs, and the explanation above disabled decision controls.
5. Switch English/Hindi, then restore the desired language. No user evidence
   should be discarded to complete any of these checks.
