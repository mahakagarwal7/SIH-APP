## Behavior and scope

Users with more than one active project membership previously saw only the first project and could not change it. Roadmap 2.1 adds a production-RLS-backed project chooser, remembers the verified choice per account, and makes Field Home show the selected project's current assignments and latest report context. The header, My work and voice/text/photo capture now consume the same selection.

## Contract and decisions

- Reads existing `project_members` and `projects` rows and the existing 1.1 schedule/assignment contract through the authenticated Supabase client.
- Uses the owner-approved existing authenticated reads under production RLS; no schema, policy or web API changes.
- Treats online membership results as authoritative. Removed access falls back to another active project or clears the local choice.
- Stores one verified project context per user in the existing app-private SQLite database. A remembered context is used only for the same account while offline.
- Cancels and removes project-scoped My work and Home report caches before changing selection.
- Reads recent production reports by both author and selected project. Native Home also includes same-account local drafts/outbox entries for that project.

## Manual device checks

1. Sign in to an account with two active memberships; confirm both names and roles appear under Change project.
2. Select the second project; confirm the header, Home, My work and a newly saved report all use that project.
3. Restart online, then restart in airplane mode; confirm only the same account sees the remembered project and switching is disabled offline.
4. Reconnect after removing that membership in the approved test setup; confirm its assignments/reports disappear and the app falls back or shows no access.
5. Sign out and sign in as another user; confirm no project, assignment or report from the first account appears.
6. Check a project with no current assignments and no reports; confirm the explicit empty states.
