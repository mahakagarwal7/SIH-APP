# PR: Restyle the field Home screen

## Behavior and scope

UI step 8.1 rebuilds the field Home screen around the supplied mobile
reference. The screen now has a Nirmaan header with an account/settings action,
a single project summary card, four large report and work actions, and the
approved four-tab field navigation.

The project card shows an exact activity completion percentage for the active
schedule, the selected project, the current assignment and its site when
available, and an honest timing status. The current assignment remains visible
on Home as required by Feature 5. Loading, error, no-access, empty-schedule and
offline states remain explicit.

The action grid opens the existing voice report, photo report and My Work
routes. **View Progress** temporarily opens My Work, where accepted progress is
already shown per task. UI step 8.6 will replace that destination with the
project-wide Progress Overview.

## Contract and design decisions

- Production queries, RPCs, tables and RLS behavior are unchanged. The screen
  uses the existing active schedule snapshot and assignment queries.
- Completion is `actual_finish` rows divided by all activities in the active
  schedule. Reported quantities and accepted percentages do not mark an
  activity complete.
- **DELAYED** appears when an unfinished activity is past `planned_finish` or
  when its actual finish is later than planned. **ON TIME** appears only when
  every activity has timing data and none is late. Otherwise the card says
  **TIMING NOT RECORDED**.
- An empty active schedule displays an em dash rather than an invented zero
  percent.
- The approved field tabs remain **Home**, **Report**, **My work** and
  **My reports**. Alerts remain deferred, and account controls stay in the
  header.
- The reference's large percentage is rendered as an exact number. A full
  green completion ring appears only at 100 percent so the decoration cannot
  imply more progress than the data supports.
- New visible labels have English and Hindi coverage.
