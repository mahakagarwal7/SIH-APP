## Problem and result

The Release workflow previously required an existing version tag for a manual
run and published every successful APK. A manual run with a blank tag now builds
and uploads a verified ARM64 APK as a private workflow artifact. Version-tag
pushes and manual runs naming an existing tag retain the publishing behavior.

## Validation

- [ ] Prettier and workflow YAML parsing pass.
- [ ] GitHub CI passes at this branch head.
- [ ] Manual build-only Release run uploads an APK and SHA256SUMS without creating
      a GitHub Release.
- [ ] APK checksum, package ID, ABI, bundled JavaScript and signature are checked
      against the build output.

## Manual device checks

Install the exact APK from the run on an ARM64 phone with Metro stopped. Sign in
with a scoped test account, restart, capture real media, test offline save and
reconnect, then confirm the report in the planner web app. Record device model,
Android version, source commit and APK SHA-256. Backend verification requires the
`verification_context_v2` migration before testing that manager path.
