## Problem and result

The Release workflow previously required an existing version tag for a manual
run and published every successful APK. A manual run with a blank tag now builds
and uploads a verified ARM64 APK as a private workflow artifact. Version-tag
pushes and manual runs naming an existing tag retain the publishing behavior.

skipped, and the repository still has no GitHub Release. The original attempt
completed Gradle but failed on a missing `Get-FileHash` cmdlet; a tested .NET
SHA-256 helper fixed that post-build failure.
