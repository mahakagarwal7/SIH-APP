# PR: Make report evidence inputs independent

## What this changes

Field reports now accept all seven non-empty combinations of voice, typed text
and photos. A voice draft and its optional typed/photo companion share one
capture ID and are frozen into one production `reserve_field_capture` manifest.
Existing voice-only, text-only, photo-only and text-plus-photo drafts remain
compatible.

The confirmation and My Reports flows derive readiness from the evidence that
is actually attached. Voice evidence waits for its verified transcript; typed
or photo evidence does not depend on the other input types. Combined typed and
voice wording is presented together for review. Because the production
`submit_field_capture` RPC requires 1–10,000 characters and the existing photo
worker validates images without OCR, photo-only reports start with an honest,
editable “Photo evidence submitted.” phrase before the reporter confirms and
sends them.

The voice screen accepts optional typed details and up to three photos alongside
the recording. Local persistence completes for the shared capture before the
outbox coordinator is notified, preventing a partial manifest from being
uploaded.

## Production contract

- Uses the existing authenticated `reserve_field_capture`, storage upload,
  `finalize_field_media` and `submit_field_capture` chain under RLS.
- Keeps the production limit of one PCM16 WAV and three JPEG photos.
- Changes no Supabase schema, RPC, worker, policy or web API.
- Includes the supplied Phase 7 and UI specification documents at
  `docs/FIXES.md` and `docs/UI_SPEC.md`; the reference PDFs remain local review
  inputs.

## Tests

- Pure readiness tests cover V, T, P, VT, VP, TP and VTP, plus empty evidence
  and pending voice transcription.
- Outbox service tests confirm and submit every one of the seven combinations.
- Native outbox tests verify that combined local evidence becomes one frozen
  manifest.
- Voice-screen coverage verifies that typed text and selected photo bytes use
  the recording's capture identity.
- Run `npm run typecheck`, `npm run lint`, `npm run format:check`, `npm test` and
  `npm run bundle:check`.

## Manual test

1. Sign in as a field user with an active project.
2. Save and send a typed-only report, then a photo-only report. Confirm that
   each opens Check and send without asking for another evidence type.
3. Save a voice-only report and wait for its transcript. Confirm and send it.
4. From the Voice report screen, add typed details and/or photos before making
   the recording. Verify VT, VP and VTP each appear as one My Reports item with
   one media bundle.
5. Save a typed report with a photo and verify TP behaves the same way.
6. For photo-only, check that the editable confirmation wording says “Photo
   evidence submitted.” and revise it if a more specific description is known.
7. Repeat one combined capture offline, reconnect, and verify its frozen media
   set syncs without splitting into separate reports.

## Assumptions and remaining work

- A voice input is ready for final submission only after the existing worker
  returns a non-empty transcript, as required by step 7.1.
- Step 7.2 owns the redesigned immediate voice review, automatic transcription
  presentation and Cancel/Send timing.
- Steps 7.3–7.5 and all Phase 8 visual work remain separate PRs.
