# English and Hindi interface completion

## What changed

- Added a root English/Hindi locale provider with a durable, validated
  SecureStore preference and English fallback.
- Added language selection to sign-in and Account so it is available before
  and after authentication.
- Localized the completed Field, Manager, navigation, authentication, empty,
  loading, error, offline and confirmation interfaces, including native alert
  actions and screen-reader labels.
- Applied locale-aware Indian dates and quantities while preserving backend
  date identifiers and all production/user content verbatim.
- Kept Devanagari on the platform system font and retained scalable, wrapping
  controls.
- Added source-level translation coverage and preference behavior tests.

## Assumptions and boundaries

- This implements approved delivery-plan slice 14 as roadmap 6.3.
- English is the default. Hindi is a device preference rather than an account
  or production-backend field.
- Project/activity names, evidence, reports and other server or user content
  remain in their recorded language.
- Tamil remains outside approved scope. No Supabase schema, policy, RPC,
  Storage or web API changed.

## Manual review

1. Cold-launch signed out, choose **हिन्दी**, close the app and confirm Hindi
   returns after relaunch.
2. Sign in and visit Field Home, Report, My work and My reports. Exercise text
   inputs and a discard alert; confirm visible and TalkBack copy is Hindi while
   project/report content is unchanged.
3. Visit Manager Overview, Review, Schedule and History. Expand records and
   confirm date, quantity and interpolated accessibility descriptions are
   localized.
4. In Account, switch to English and confirm the already-mounted workspace
   updates without signing out or changing project.
5. Repeat both languages with the device font size at its largest setting and
   TalkBack enabled. Check tabs, long buttons, forms and Devanagari clipping.
6. Simulate preference-storage failure in a development build and confirm the
   current language stays active with an error message.
