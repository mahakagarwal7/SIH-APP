## Behavior and scope

On the installed version 159 APK, Field Home showed an empty progress ring,
“Site not recorded,” and “No assignment today” for a planner with no personal
assignments. Those labels looked like missing project data even though the
project has an active schedule. Home now shows an explicit personal-assignment
empty state. A planner can open the project schedule from it; a reporter sees
guidance to check assignments with a supervisor. If no schedule is active,
Home says so directly. The four existing report/work actions remain available.

The same APK placed a long project title and its “Selected” state in one row,
clipping the state on a narrow screen. The project card now stacks the full
title, a selected-state pill, and membership details. When the account has
only one project, the chooser says that plainly and disables a no-op selection.
Both cards use the existing Nirmaan navy, blue and white visual language, with
large touch targets and English/Hindi copy.

## Contract and decisions

- Existing authenticated project membership, schedule snapshot and personal
  assignment data are unchanged. No backend or RLS change.
- A planner's full project schedule is different from their own field
  assignments; no project-wide progress is inferred from an empty personal
  list.
- The selected project remains the only choice when the active membership
  query returns one project. The chooser does not manufacture alternatives.

## Manual device checks

1. Install the new APK as an update without clearing app data. In Account,
   confirm its source commit is the new main commit.
2. With the same planner account, open Field Home. Confirm there is no empty
   progress ring or “Site not recorded.” Open project schedule from the new
   card; the schedule should still show project activities.
3. Open Change project. The sole project must show its complete name and a
   visible “Selected” pill. Back returns to Field Home. A second project,
   when available to a test account, must remain selectable.
4. Check a reporter account with zero assignments, a project without an active
   schedule, offline cached data, English/Hindi and increased Android font size.
   Existing assigned-work summaries and report actions should still work.

## Remaining limitations

This change addresses the two reproduced screens. It does not claim that every
report, review or synchronization path has passed an end-to-end production
test. Field Home's “View Progress” action still opens task-level My Work, as
it did before this fix.
