# Manager overview: show the field reporter for accepted updates

## What changed

Recent accepted updates now use the author of a native text or voice report when imported provenance has no reporter label. The lookup reads only the current project's five recent accepted reports under the signed-in manager's RLS access, then rechecks manager membership. Spreadsheet imports still use their recorded source label; their uploader is never presented as the field reporter. If neither source identifies a reporter, the existing “Reporter not recorded” fallback remains.

## Verification

- The reporter-name service, model and screen regressions failed before the corresponding fixes and pass afterward. A separate regression rejects spreadsheet-uploader mislabeling.
- `npm run typecheck`, `npm run lint`, `npm run format:check`, `npm test -- --runInBand` (80 suites, 599 tests) and `npm run bundle:check` passed.
- Against the disposable local Supabase seed, a fixture report was accepted through the planner web UI. The configured mobile web export showed its real author, Arun Saikia, in Manager Overview at 390px without horizontal overflow or page errors. This browser check does not exercise native media or offline storage.

## Device check

Install the APK built from this commit over the existing package, open Manager → Overview with an account that can view an accepted native field report, and confirm Recent verified field updates shows its reporter's name. Check that an imported spreadsheet without a reported-by label does not show the importer's name as a field reporter.
